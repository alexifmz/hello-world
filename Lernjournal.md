## Einführung zu Github
- Repo: Der Projektordner
- Fork: Ein Kopie eines fremden Repo
- Clone: Herunterladen von das Fork das du gemacht hast
- Branch: Isolierter Arbeitszweig pararell zu Hauptversion
- Commit: Commit ist eigentlich speichern, eigentlich wie in Snapshot
- Push: Hochladen lokalen commits vom Computer auf GitHub
- Issue: Ein Ticket oder Eintragsfeld im Repo um Fehler zu melden

## Introduction to GitHub administration

- Owner: Hat kontrolle über die "Organisation".
- Member: Mitglied von die Organisation
- Billing Manager: Berechnet Abzahlungen und zahlungsdaten
- Security Manager: Steuert sicherheitswarnungen

  Muss noch ein bisschen lernen uber:

- Read: Ich weiss dass sie Repos ansehen können 
- Triage: Kann issues pullen und requests verwalten.
- Write: Kann direkt code pushen
- Maintain: Repository Einstellungen verwlaten
- Admin: Wie ein owner, hat administrative Kontrolle
